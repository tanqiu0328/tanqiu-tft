# Triage 标签

工程技能使用五种标准 triage 角色。本文件将这些角色映射到仓库问题跟踪器中的实际标签

| mattpocock/skills 中的标签 | 本仓库标签        | 含义                       |
| -------------------------- | ----------------- | -------------------------- |
| `needs-triage`             | `needs-triage`    | 需要维护者评估该问题       |
| `needs-info`               | `needs-info`      | 等待报告者补充信息         |
| `ready-for-agent`          | `ready-for-agent` | 规格完整，可交由 AFK agent |
| `ready-for-human`          | `ready-for-human` | 需要人工实现               |
| `wontfix`                  | `wontfix`         | 不会处理                   |

当技能提及某种角色时，应使用表格右栏对应的实际标签

如果仓库以后调整标签命名，可直接修改右栏
